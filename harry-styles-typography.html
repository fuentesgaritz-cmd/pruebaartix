03

Tipografía para Harry Styles

Una tipografía modular creada desde cero para el álbum Kiss All the Time Disco Occasionally.

La tipografía es una propuesta modular desarrollada desde cero para el nuevo álbum Kiss All the Time Disco Occasionally. El sistema nace a partir de los módulos de un círculo y un cuadrado, dos formas básicas que organizan todo el alfabeto y generan un lenguaje visual coherente, tecnológico y reconocible.

La combinación entre círculo y cuadrado hace alusión a una cámara, un elemento con mucho peso dentro del álbum. Esta referencia conecta directamente con el single Aperture, una canción que habla de abrirse, mostrarse tal y como eres y relacionarte con los demás desde la honestidad.

04

Pictogramas del álbum

Además del alfabeto, desarrollé una serie de pictogramas para las canciones del disco utilizando los mismos módulos de círculo y cuadrado. Cada icono mantiene la lógica del sistema y se muestra sobre fondo blanco para asegurar una lectura nítida.

05

Aplicaciones del sistema

Aquí se reúne una cuadrícula de aplicaciones del sistema en distintos soportes —camisetas, vallas, portada del álbum, credenciales, chapas, tarjetas, editorial y escenografía—. Pulsa sobre cualquier imagen para ampliarla y vuelve a pulsar para devolverla a su tamaño original.

06

El proceso detrás del proyecto

Como cierre del proyecto, este documental recoge el proceso de creación: desde la construcción de la tipografía modular y el desarrollo de los pictogramas hasta sus distintas aplicaciones visuales. Una mirada al trabajo, las pruebas y las decisiones que dieron forma al sistema.
